# Книжный магазин «Между строк»

Лабораторные работы №1 и №2. Статический сайт на HTML и CSS.

Для просмотра откройте index.html в браузере. Установка программ и сборка не нужны. Для карты требуется интернет, для ссылки заказа — настроенная почтовая программа.

## Страницы

- index.html — главная и карта сайта.
- about.html — история, цель и преимущества магазина.
- catalog.html — список шести книг.
- pride.html, prince.html, master.html, alice.html, sherlock.html, sea.html — отдельные страницы книг с описанием, характеристиками, ценой и ссылкой заказа по почте.
- price.html — таблица цен.
- contacts.html — контакты и карта проезда.
- style.css — общие стили.
- images — логотип и обложки.

Магазин, цены, контакты и обложки условные. Реальные заказы не принимаются.

## Публикация

Загрузите содержимое папки в репозиторий GitHub. В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root), затем сохраните настройки. После публикации проверьте все страницы по выданному адресу. Файл .nojekyll уже добавлен.

## Проверка разметки

HTML можно проверить загрузкой каждого файла на https://validator.w3.org/nu/.
CSS можно проверить загрузкой style.css на https://jigsaw.w3.org/css-validator/.
