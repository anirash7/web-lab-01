# Лабораторная работа №1

Тема: книжный магазин «Между строк».

Сайт сделан на HTML и CSS, без JavaScript, библиотек и сборки.

## Как открыть

Открыть файл index.html в браузере.

## Файлы

- index.html — главная страница и карта сайта.
- catalog.html — каталог из шести книг.
- price.html — таблица цен.
- about.html — информация о магазине.
- contacts.html — контакты и карта проезда.
- style.css — стили всех страниц.
- images — картинки обложек в формате JPEG.

## Кратко о коде

header — шапка, nav — меню, main — содержимое, footer — подвал.
Ссылки сделаны тегом a, картинки — img, список — ul и li, таблица — table, tr, th и td.
Файл style.css подключён тегом link в head каждой страницы.
Точка в CSS означает класс: .book оформляет блоки с class="book".
Цвета задаются background-color и color. margin — внешние отступы, padding — внутренние.
max-width ограничивает ширину содержимого. На маленьком экране текст переносится, меню занимает несколько строк, таблица может прокручиваться.

Магазин, цены и контакты вымышлены. Обложки созданы для учебного примера. Карта загружается через интернет.

## GitHub Pages

После загрузки в GitHub нужно включить публикацию из ветки main и корневой папки репозитория в Settings → Pages. В корне лежит index.html.
